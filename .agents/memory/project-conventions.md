# Project Conventions

## Git Workflow
- Always create a new dedicated branch for major code changes.
- Branch name format should follow: `feature/[task-slug]` or `fix/[bug-slug]`.

## Supported AI platforms (Fork)
- This kit is designed to empower both Google Antigravity and Claude Code (claude.ai/code), as well as Gemini CLI.
- Skills and agents conform to portable Markdown + YAML frontmatter contracts for maximum cross-runtime capability.
